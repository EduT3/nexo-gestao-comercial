# Revisão do README — Docs Experience M1

O README apresenta o produto e o download público antes dos detalhes técnicos. A galeria usa capturas do aplicativo Windows da execução 43650469127 em perfis fictícios. Início foi capturado na versão de origem. Vendas, Produtos e estoque e Guard foram capturados na candidata. As quatro imagens foram reduzidas para até 1.100 px de largura e conferidas visualmente. O Guard aparece com os campos de PIN vazios.

A revisão separa a release 1.0.4, o instalador de teste dentro de um ZIP do Actions e a execução portátil. Explica a identificação por nome, o papel do Guard e a guarda separada da política e da chave. Move os registros históricos para [a cópia do README anterior](history/README-before-docs-m1.md) e mantém os relatórios de atualização e desempenho por referência.

A página de release foi conferida pelo GitHub, com o instalador, o manifesto, o blockmap e SHA256SUMS. A prévia web respondeu HTTP 200. A matriz Windows cliente permanece em aberto. [Procedimento de homologação](WINDOWS-COMPATIBILITY.md)

O Markdown foi renderizado pela API do GitHub. A renderização foi exercitada no Edge local em 390 e 1.280 px, com a galeria expandida e as cinco imagens válidas. O teste usou o HTML gerado pelo GitHub com estilos locais de apresentação. Os links internos foram conferidos no repositório.
